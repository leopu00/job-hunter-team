    Create your VPS

    We'll guide you through creating a Hetzner server.

    1. Generate your SSH key

    JHT keeps the private key on this PC (chmod 600), never in the cloud. It's used only for the one-shot install handshake — after that the VPS talks to JHT via HTTPS + pairing token.

    2. Create the VPS on Hetzner

    Open the Hetzner console, pick CPX22, paste the public key.

    To share VPS access with a teammate or use it from another PC, send them both files from this folder (jht_ed25519 and jht_ed25519.pub). They go in the recipient's ~/.ssh/ directory.

    3. Paste the server IP

        Cloud sync
        
            
        

            
            
        
              
        
                Set a passphrase to encrypt your launcher config before it's uploaded. The passphrase never leaves this device.
              
        
              
        
                Why a passphrase if I'm already signed in?
                
        
                  Sign-in proves who you are; the passphrase encrypts the data before it leaves your computer. Without it, server admins (and anyone who dumps the database) can read your synced data. With it, only this device can. Trade-off: if you lose the passphrase, the cloud data is unrecoverable by design.
                
        
              
        
              
              
              
        
                Save it in your password manager NOW. If you lose it, your cloud data cannot be recovered.
              
        
              
        
                
              
        
              
        
            
        

            
            
        
              
        
                Cloud sync is set up on this device. Enter your passphrase to unlock it.
