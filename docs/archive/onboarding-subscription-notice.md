## Titolo
**Subscriptions, not API keys**

## Lead
> The team keeps many AI agents running in parallel, around the clock. API
> keys bill per token and would cost hundreds per day. A flat subscription
> keeps your spend predictable.

## Hint (raccomandazione)
> **Strongly recommended:** use a subscription dedicated to the team — not
> the one you already use for work or personal tasks. A shared account
> drains the same weekly quota twice.

## Confronto costi

| Pay-per-token (API) | vs | Abbonamento (Claude Max 20×) |
|---|---|---|
| **$1,000–$2,500/mo** | | **$200/mo** |
| ~200–400M tokens/mo (mix Sonnet 4.6) | | stesso utilizzo, costo fisso |

$15/M output per Sonnet 4.6) e finestre di 5 ore sature contro il cap
settimanale di Max 20×. Il risparmio reale dipende dal mix input/output.
